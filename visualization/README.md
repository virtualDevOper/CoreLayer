# Flight Data Visualizer

Кроссплатформенное приложение с графическим интерфейсом для визуализации данных симуляции полёта летательных аппаратов.

## Возможности

- **Загрузка данных**: Поддержка CSV и TXT файлов с автоматическим определением разделителя
- **Управление файлами**: Загрузка, удаление, выбор файлов с удобными кнопками
- **Множественный выбор**: Одновременная работа с несколькими файлами и переменными
- **Типы графиков**: Линейные, точечные, столбчатые и 3D графики
- **Интерактивность**: Масштабирование, перемещение, отображение значений при наведении
- **Экспорт**: Сохранение графиков в PNG, PDF, SVG форматах
- **Производительность**: Оптимизированная загрузка больших файлов
- **Горячие клавиши**: Быстрый доступ к основным функциям
- **Кроссплатформенность**: Работает на Windows, Linux, macOS

## Установка

### Требования
- Python 3.7 или выше
- pip (менеджер пакетов Python)

### Установка зависимостей

```bash
# Перейти в папку visualization
cd visualization

# Установить зависимости
pip install -r requirements.txt
```

### Альтернативная установка (если requirements.txt не работает)

```bash
pip install pandas matplotlib numpy
```

## Запуск

```bash
# Из папки visualization
python flight_data_visualizer.py

# Или из корня проекта
python visualization/flight_data_visualizer.py
```

## Использование

### 1. Загрузка данных
- Нажмите кнопку "Load Files" или используйте меню File → Load Files (Ctrl+O)
- Выберите один или несколько файлов с данными симуляции
- Поддерживаемые форматы: `.txt`, `.csv`
- Файлы должны содержать заголовки в первой строке
- Загруженные файлы автоматически выбираются для построения графиков

### 2. Управление файлами
- **Load Files**: Загрузить новые файлы данных
- **Remove Files**: Удалить выбранные файлы из списка
- **Select All**: Выбрать все загруженные файлы
- **Deselect All**: Снять выбор со всех файлов

### 3. Выбор данных для визуализации

#### 📊 Simple Mode (по умолчанию)
- **Loaded Files**: Выберите файлы для отображения (можно несколько)
- **X-Axis**: Выберите переменную для оси X (обычно `time`)
- **Y-Axis**: Выберите одну или несколько переменных для оси Y
- **Select All Y**: Выбрать все доступные Y-переменные
- **Clear Y**: Снять выбор со всех Y-переменных

#### 🔧 Advanced Mode (расширенный)
- Переключитесь на режим "Advanced" 
- Появятся **вкладки для каждого файла**
- В каждой вкладке выбирайте переменные **индивидуально для каждого файла**
- Позволяет строить графики с **разными переменными из разных файлов**

### 4. Настройка графика
- **Plot Type**: Выберите тип графика:
  - **Line**: Линейный график (по умолчанию)
  - **Scatter**: Точечный график
  - **Bar**: Столбчатый график
  - **3D Plot**: 3D график (требует минимум 2 Y-переменные)

### 5. Создание и экспорт
- Нажмите **"📊 Plot"** для создания графика (или F5)
- Используйте панель инструментов matplotlib для навигации  
- Нажмите **"💾 Save Plot"** для экспорта в файл

## Формат данных

Приложение автоматически определяет структуру файлов. Поддерживаемый формат:

```csv
time,position_x,position_y,position_z,velocity_x,velocity_y,velocity_z
0.0,0.0,0.0,0.0,50.0,0.0,0.0
0.01,0.499672,-0.000410427,0.000210278,49.9491,-0.0781245,0.0420169
...
```

### Особенности:
- Первая строка должна содержать заголовки столбцов
- Разделитель: запятая (`,`) или табуляция
- Числовые данные в формате с плавающей точкой
- Пустые значения автоматически обрабатываются

## Примеры переменных

Типичные переменные в файлах симуляции:
- `time` - время симуляции
- `position_x`, `position_y`, `position_z` - координаты положения
- `velocity_x`, `velocity_y`, `velocity_z` - компоненты скорости
- `angularVelocity_x`, `angularVelocity_y`, `angularVelocity_z` - угловые скорости
- `eulerAngles_x`, `eulerAngles_y`, `eulerAngles_z` - углы Эйлера
- `mass` - масса объекта
- `totalForce_x`, `totalForce_y`, `totalForce_z` - компоненты силы

## Интерактивные возможности

### Панель инструментов matplotlib:
- **Home**: Возврат к исходному масштабу

- **Pan**: Перемещение графика

- `Ctrl+S`: Сохранить график
- `Ctrl+A`: Выбрать все файлы
- `Delete`: Удалить выбранные файлы
- `F5`: Создать график

- `Page Up/Page Down`: Быстрая прокрутка Y-переменных

## Устранение неполадок

### Ошибки загрузки файлов
- Проверьте формат файла (CSV с заголовками)
- Убедитесь, что файл содержит числовые данные
- Проверьте кодировку файла (рекомендуется UTF-8)

### Проблемы с производительностью
- Для очень больших файлов (>100MB) загрузка может занять время
- Приложение автоматически оптимизирует типы данных
- При необходимости можно загружать файлы по частям

### Ошибки отображения
- Убедитесь, что выбраны корректные переменные
- Проверьте, что данные не содержат только пустые значения
- Для 3D графиков требуется минимум 2 Y-переменные
