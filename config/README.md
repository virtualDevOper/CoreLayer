# Руководство по конфигурационным файлам

Эта директория содержит конфигурационные файлы для настройки симуляции баллистического полета.

## Оглавление
1. [simulation.json](#simulationjson) - Основная конфигурация симуляции
2. [geometry_config.json](#geometry_configjson) - Конфигурация геометрии объектов
3. [aerodynamics_calibration.json](#aerodynamics_calibrationjson) - Калибровка аэродинамической модели

---

## simulation.json

Основной конфигурационный файл симуляции. Определяет параметры решателя, объекты и их начальные условия.

### Глобальные параметры

| Параметр | Тип | Описание | Пример |
|----------|-----|----------|--------|
| `operator_name` | string | Имя оператора симуляции (для логирования) | `"Ilya Berulava"` |
| `ode_solver` | string | Тип решателя ОДУ | `"RK-4"` (Runge-Kutta 4-го порядка) |
| `world_config` | string | Конфигурация мира | `"Simple world"` |
| `data_saver` | string | Формат сохранения данных | `"txt"` или `"csv"` |
| `earth_type` | string | Модель Земли | `"flat earth"` или `"spherical earth"` |
| `time_step` | float | Шаг интегрирования (секунды) | `0.05` |
| `max_time` | float | Максимальное время симуляции (секунды) | `3.0` |
| `output_csv` | string | Путь к выходному файлу | `"data/output/results_data/simulation_data.csv"` |

### Массив aircraft

Каждый объект в массиве `aircraft` описывает один летательный аппарат/снаряд.


#### data_tables - Таблицы изменяющихся параметров

Все параметры задаются как функции времени в текстовых файлах формата:
```
время1 значение1
время2 значение2
...
```

Система использует линейную интерполяцию между точками.

##### Тяга двигателя (в связанной системе координат)

| Параметр | Единицы | Описание | Как рассчитать |
|----------|---------|----------|----------------|
| `thrust_x` | Ньютоны (N) | Тяга вдоль оси X (вперед) | Из характеристик двигателя: тяга × cos(угол_отклонения) |
| `thrust_y` | Ньютоны (N) | Тяга вдоль оси Y (вправо) | Обычно 0, если нет управления вектором тяги |
| `thrust_z` | Ньютоны (N) | Тяга вдоль оси Z (вверх) | Из характеристик двигателя: тяга × sin(угол_отклонения) |

**Пример расчета:**
- Двигатель с постоянной тягой 1000 N в течение 2 секунд:
  ```
  # Thrust_x_t.txt
  0.0 1000.0
  2.0 1000.0
  2.01 0.0
  10.0 0.0
  ```

##### Масса

| Параметр | Единицы | Описание | Как рассчитать |
|----------|---------|----------|----------------|
| `mass` | килограммы (kg) | Полная масса объекта | m(t) = m₀ - ṁ·t, где ṁ - расход топлива |

**Пример расчета:**
- Начальная масса: 10 кг
- Расход топлива: 0.5 кг/с в течение 2 секунд
  ```
  # Mass_t.txt
  0.0 10.0
  2.0 9.0
  10.0 9.0
  ```

##### Моменты инерции

| Параметр | Единицы | Описание | Как рассчитать |
|----------|---------|----------|----------------|
| `Ixx` | кг·м² | Момент инерции относительно оси X | Зависит от геометрии и распределения массы |
| `Iyy` | кг·м² | Момент инерции относительно оси Y | Для цилиндра: I = (1/12)m(3r² + h²) |
| `Izz` | кг·м² | Момент инерции относительно оси Z | Для сферы: I = (2/5)mr² |

**Как рассчитать:**
1. **Простые формы** - используйте аналитические формулы
2. **Сложная геометрия** - используйте CAD-систему (SolidWorks, Fusion 360)
3. **Изменение во времени** - пересчитывайте при изменении массы:
   - I(t) = I₀ × (m(t)/m₀) для однородного выгорания
   - Для неоднородного - требуется детальный расчет

**Пример:**
```
# Ix_t.txt - для ракеты длиной 1м, диаметром 0.1м
0.0 0.0833  # полная масса 10 кг
2.0 0.0750  # масса 9 кг после выгорания
10.0 0.0750
```

##### Центр масс (COM - Center of Mass)

| Параметр | Единицы | Описание | Использование в расчетах |
|----------|---------|----------|--------------------------|
| `com_x` | метры (m) | X-координата ЦМ в связанной СК | **Критически важен** для расчета моментов от аэродинамических сил |
| `com_y` | метры (m) | Y-координата ЦМ в связанной СК | Обычно 0 для осесимметричных объектов |
| `com_z` | метры (m) | Z-координата ЦМ в связанной СК | Обычно 0 для осесимметричных объектов |

**Как используется в физике:**

Центр масс критически важен для расчета моментов. Аэродинамические силы приложены в центре давления (CP), а уравнения движения записаны относительно центра масс (CM).

Момент от аэродинамической силы:
```
M = r × F
где r = CP - CM (вектор от центра масс до центра давления)
```


**Как рассчитать:**

1. **Для простых форм:**
   - Однородный цилиндр: COM в геометрическом центре
   - Конус: COM на расстоянии h/4 от основания

2. **Для сложных объектов:**
   - Используйте CAD-систему (SolidWorks, Fusion 360)
   - Или рассчитайте как взвешенное среднее компонентов:
     ```
     x_cm = Σ(m_i × x_i) / Σ(m_i)
     ```

3. **Изменение во времени (для ракет):**
   - При выгорании топлива ЦМ смещается
   - Если топливо в хвосте - ЦМ смещается вперед

**Пример для ракеты:**
```
# COM_x_t.txt - ракета длиной 1м, топливо в хвосте
0.0 0.45   # ЦМ ближе к хвосту (полный бак)
2.0 0.52   # ЦМ сместился вперед (топливо выгорело)
10.0 0.52
```

**Система координат:**
- Начало координат: обычно в центре масс ракеты
- X: вдоль продольной оси (вперед)
- Y: вправо
- Z: вверх

#### geometry - Геометрия объекта

| Параметр | Тип | Описание |
|----------|-----|----------|
| `stl_files` | array[string] | Массив путей к STL-файлам геометрии |

STL-файлы используются для расчета аэродинамических коэффициентов методом панелей.

#### initial_conditions - Начальные условия

| Параметр | Единицы | Описание | Пример |
|----------|---------|----------|--------|
| `position` | [x, y, z] метры | Начальная позиция в мировой СК | `[0.0, 0.0, 0.0]` |
| `velocity` | [vx, vy, vz] м/с | Начальная скорость в мировой СК | `[48.3, 0.0, 12.9]` |
| `euler` | [roll, pitch, yaw] градусы | Начальная ориентация (углы Эйлера) | `[0.0, 15.0, 0.0]` |
| `angular_velocity` | [ωx, ωy, ωz] рад/с | Начальная угловая скорость | `[0.0, 0.0, 0.0]` |

**Система координат:**
- Мировая СК: X - восток, Y - север, Z - вверх (или другая, зависит от `earth_type`)
- Углы Эйлера: roll (крен), pitch (тангаж), yaw (рыскание)

## geometry_config.json

Конфигурация геометрии объектов и их аэродинамических характеристик.

### Структура для каждого объекта

```json
{
  "object_name": {
    "output_combined": "combined_file.stl",
    "components": ["..."]
  }
}
```

### Поля компонента

| Параметр | Тип | Описание | Как рассчитать |
|----------|-----|----------|----------------|
| `name` | string | Имя компонента | Произвольное |
| `source_stl` | string | Путь к исходному STL | Относительно `data/input/geometry/` |
| `output_stl` | string | Путь к обработанному STL | Относительно `data/input/geometry/` |

#### metadata - Аэродинамические характеристики

| Параметр | Единицы | Описание | Как рассчитать |
|----------|---------|----------|----------------|
| `S_ref` | м² | Характерная площадь | Площадь миделя (максимального поперечного сечения) |
| `b_ref` | м | Характерный размах | Для крыла: размах, для ракеты: диаметр |
| `c_ref` | м | Характерная хорда | Для крыла: средняя хорда, для ракеты: длина |
| `lambda` | безразм. | Удлинение | λ = b²/S для крыла, λ = L/D для ракеты |
| `type` | string | Тип компонента | `"FUSELAGE"`, `"WING"`, `"TAIL"` |

**Примеры расчета:**

1. **Для ракеты (цилиндр):**
   - Диаметр D = 0.07 м, длина L = 0.5 м
   - `S_ref` = π(D/2)² = 0.00385 м²
   - `b_ref` = D = 0.07 м (диаметр)
   - `c_ref` = L = 0.5 м (длина)
   - `lambda` = L/D = 0.5/0.07 ≈ 7.14

2. **Для крыла:**
   - Размах b = 2 м, площадь S = 0.5 м²
   - `S_ref` = 0.5 м²
   - `b_ref` = 2 м
   - `c_ref` = S/b = 0.25 м (средняя хорда)
   - `lambda` = b²/S = 4/0.5 = 8

#### transform - Трансформация геометрии

| Параметр | Описание |
|----------|----------|
| `offset` | [x, y, z] смещение в метрах |
| `rotation_axis` | [x, y, z] ось вращения (единичный вектор) |
| `rotation_angle_deg` | Угол поворота в градусах |

## aerodynamics_calibration.json

Калибровочные коэффициенты для настройки аэродинамической модели под экспериментальные данные.

### Структура calibration

#### subsonic - Дозвуковой режим (M < 0.7)

| Параметр | Описание | Диапазон | По умолчанию |
|----------|----------|----------|--------------|
| `k_lift` | Множитель подъемной силы | 0.5 - 2.0 | 1.0 |
| `k_drag` | Множитель силы сопротивления | 0.5 - 2.0 | 1.0 |

#### supersonic - Сверхзвуковой режим (M > 1.3)

| Параметр | Описание | Диапазон | По умолчанию |
|----------|----------|----------|--------------|
| `k_lift` | Множитель подъемной силы | 0.5 - 2.0 | 1.0 |
| `k_drag` | Множитель силы сопротивления | 0.5 - 2.0 | 1.0 |

#### transonic - Трансзвуковой режим (0.7 ≤ M ≤ 1.3)

| Параметр | Описание | Диапазон | По умолчанию |
|----------|----------|----------|--------------|
| `k_wave_drag` | Множитель волнового сопротивления | 0.5 - 3.0 | 1.0 |
| `peak_mach` | Число Маха пика сопротивления | 0.9 - 1.1 | 0.95 |
| `peak_width` | Ширина пика (в единицах Маха) | 0.05 - 0.3 | 0.15 |
| `peak_magnitude` | Величина пика Cd_wave | 0.0 - 0.1 | 0.02 |

#### stall - Срыв потока

| Параметр | Описание | Диапазон | По умолчанию |
|----------|----------|----------|--------------|
| `alpha_offset_deg` | Поправка угла срыва (градусы) | -10.0 - 10.0 | 0.0 |
| `k_stall_drag` | Множитель сопротивления при срыве | 0.5 - 3.0 | 1.0 |

#### ground_effect - Эффект земли

| Параметр | Описание | Диапазон | По умолчанию |
|----------|----------|----------|--------------|
| `k_lift` | Множитель подъемной силы у земли | 0.8 - 1.5 | 1.0 |
| `k_drag` | Множитель сопротивления у земли | 0.5 - 1.2 | 1.0 |

### Процесс калибровки

1. **Начните с k_* = 1.0** (без коррекции)
2. **Запустите симуляцию** и сравните с экспериментальными данными
3. **Корректируйте постепенно:**
   - Если модель недооценивает подъемную силу → увеличьте `k_lift`
   - Если модель переоценивает сопротивление → уменьшите `k_drag`
4. **Итерируйте** до достижения приемлемой точности

### Примеры из файла

В файле есть примеры калибровки для:
- **Cessna 172** (легкий самолет)
- **F-16** (истребитель)

Используйте их как отправную точку для похожих объектов.
