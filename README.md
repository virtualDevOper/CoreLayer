# CoreLayer - Rocket Simulation Framework

Система моделирования полета абстрактного летательного аппарата с максимально абстрактной архитектурой.

Поддерживает создание большого количества объектов: несколько ракет, рой БПЛА, несколько целей, стая птиц и т.д. 

В данном репозитории реализован слой ядра программы. Планируется слой визуализации данных на Unreal Engine для отрисовки полета (как в Microsoft Flight Simulator).

Архитектура максимально абстрактна для поддержки различных типов: ЗУР, ОТРК, БПЛА и других летательных аппаратов.


## Основные компоненты

### Системы динамики
- **FullRocketODE** - Полная модель динамики ракеты
- **SimpleKinematicsSystem** - Упрощенная кинематическая модель

### Решатели ОДУ
- **RungeKutta4Solver** - Метод Рунге-Кутты 4-го порядка

### Физические объекты
- **AbstractAircraft** - Базовый класс летательных аппаратов
- **GuidedMissle** - Управляемые ракеты
- **MANPAD_V1** - Конкретная реализация ПЗРК

### Модель мира
- **Атмосферная модель** - Плотность, температура, давление
- **Гравитационная модель** - Модель Кавендиша
- **Модель ветра** - Влияние ветра на полет
- **Модель рельефа** - Взаимодействие с поверхностью

## Установка и настройка

### Требования
- CMake 3.30+
- C++23 совместимый компилятор
- Eigen 3.4.0 (закидывай в папку `libs/`)

### Подготовка данных
Убедитесь, что в `data/input/...` находятся все необходимые файлы интерполируемых таблиц.

### Сборка
```bash
mkdir build/release
cd build/release
cmake ../..
make
```

### Запуск
```bash
./CoreLayer
```

## Конфигурация

Основные параметры симуляции настраиваются в `config/simulation.json`:
- Начальные условия полета
- Параметры решателя ОДУ
- Пути к файлам данных
- Настройки сохранения результатов
