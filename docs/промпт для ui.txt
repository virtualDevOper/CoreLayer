Задача: Создать кроссплатформенное десктопное приложение на Python 3.10+ с использованием только встроенной библиотеки Tkinter, позволяющее инженеру-баллистику полностью настраивать сценарии полёта без ручного редактирования JSON.

управляемый снаряд(любая ракета) - имеет разные датчики на выбор(есть возможность расширить, этот подкласс будет развиваться) Имеется автопилот Полная аэродинамика есть гсн=> можно выбрать метод наведения
неуправляемый снаряд - нет датчиков, нет автопилотов, полная ад или упрощенная, метода наведения нет
простой объект - нет дачиков, нет автопилотов, нет ад, просто точка, которая движется в определенном направлении с постоянной скоростью
БПЛА - есть датчики, есть автопилот, есть ад,(по идее очень похоже на управляемую ракету, но система оду другая будет)
Также у каждого из объектов имеется 3д модель и габариты для проверки коллизии между объектами и с землей в дальнейшем
