🚀 ПЕРВОНАЧАЛЬНАЯ НАСТРОЙКА (один раз):

Windows: Двойной щелчок по setup_build.bat
Linux:   ./setup_build.sh

🚀 ЗАПУСК ТЕСТОВ:

Windows (.bat файлы):
• run_all_tests.bat      - все тесты
• quick_tests.bat        - быстрый запуск
• unit_tests.bat         - только юнит тесты
• integration_tests.bat  - только интеграционные тесты
• mock_tests.bat         - только мок тесты
• detailed_tests.bat     - подробный вывод
• rebuild_tests.bat      - пересборка и запуск

Linux (.sh файлы):
• ./run_all_tests.sh     - все тесты
• ./quick_tests.sh       - быстрый запуск
• ./unit_tests.sh        - только юнит тесты
• ./integration_tests.sh - только интеграционные тесты
• ./mock_tests.sh        - только мок тесты
• ./detailed_tests.sh    - подробный вывод
• ./rebuild_tests.sh     - пересборка и запуск

🐍 PYTHON КОМАНДЫ (универсальные):

py run_tests.py                    - все тесты
py quick_test.py                   - быстрый запуск
py run_tests.py --type unit        - только юнит тесты
py run_tests.py --type integration - только интеграционные тесты
py run_tests.py --type mock        - только мок тесты
py run_tests.py --detailed         - подробный вывод
py run_tests.py --rebuild          - пересборка

📋 ТРИ ОСНОВНЫХ ТЕСТА:

1. 🧪 ЮНИТ ТЕСТЫ - тестируют отдельные компоненты
2. 🔗 ИНТЕГРАЦИОННЫЕ ТЕСТЫ - тестируют взаимодействие компонентов
3. 🎭 МОК ТЕСТЫ - тестируют с использованием mock объектов

💡 СТРУКТУРА ПАПОК:

tests/
├── unit/           - юнит тесты (*.cpp)
├── integration/    - интеграционные тесты (*.cpp)  
├── mocks/          - мок тесты (*.cpp)
├── *.bat           - Windows скрипты
├── *.sh            - Linux скрипты
├── run_tests.py    - основной Python скрипт
└── quick_test.py   - быстрый Python скрипт
